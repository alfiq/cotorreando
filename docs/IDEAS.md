# Ideas

Cosas que podrían venir después. Ninguna es necesaria para que funcione.

- **Comandos de voz**: «nueva línea», «punto y aparte», «borra eso».
- **Diccionario personal**: reemplazos tras la transcripción (nombres, siglas).
- **Transcripción en vivo**: mostrar texto parcial mientras hablas, usando ventanas
  deslizantes sobre el codificador.
- **Retroalimentación del blob**: un destello breve cuando una frase se descarta
  porque estabas tecleando.
- **Menos memoria**: cargar el modelo solo al activarse y liberarlo tras un rato inactivo.
- **Pegar en vez de teclear** para textos muy largos, como opción.
- **Atajo grabable**: capturar la combinación pulsando teclas en vez de escribirla.
- **Historial**: las últimas frases dictadas, para copiar de nuevo.
- **Entrenamiento con verificación**: separar unas frases para medir el WER antes y
  después del adaptador, y avisar si empeora.
